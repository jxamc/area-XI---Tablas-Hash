# Tarea Hash CSV

Proyecto realizado en C++ y Java utilizando tablas hash para la carga masiva de estudiantes desde un archivo CSV.

## Características

- Tabla hash implementada manualmente
- Separate Chaining con listas enlazadas
- Carga masiva desde CSV
- Búsqueda por student_id
- Eliminación por student_id
- Validación de duplicados
- Estadísticas de colisiones
- Factor de carga
- Mostrar buckets
